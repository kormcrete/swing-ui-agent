---
title: Reset and the starting screen
description: How each test gets the app to where it begins.
sidebar:
  order: 3
---

Before each test, open modal dialogs are closed. The app may still be on any screen, so every test begins by getting to its own starting screen, through the menu bar or a shortcut. A plugin can reset the app to a defined state instead.
