---
title: CLI or MCP?
description: Both give an agent the same tools. Pick by the agent you use.
sidebar:
  order: 1
---

The CLI suits coding agents with a shell: each call connects fresh, so there is nothing to reconnect after a rebuild. MCP over streamable HTTP at `http://127.0.0.1:8765/mcp` suits MCP clients.
