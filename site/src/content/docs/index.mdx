## What it does

It connects three things that usually happen apart:

- **A person shows** how the app should behave, in the app itself, or describes it in words.
- **A coding agent turns that** into a named, repeatable test.
- **Developers run the same test** locally and in CI, and move to an ordinary Java test when a check needs more.

## Try it in two minutes

Download Order Desk, a small Swing order-entry app with the agent built in. Nothing to build.

1. **Download** it for
   [Mac with Apple Silicon](https://github.com/kormcrete/swing-order-desk-demo/releases/latest/download/kormcrete-order-desk-macos-arm64.dmg),
   [Mac with Intel](https://github.com/kormcrete/swing-order-desk-demo/releases/latest/download/kormcrete-order-desk-macos-x64.dmg),
   [Windows](https://github.com/kormcrete/swing-order-desk-demo/releases/latest/download/kormcrete-order-desk-windows-x64.zip)
   or [Linux and any Java 8+](https://github.com/kormcrete/swing-order-desk-demo/releases/latest/download/kormcrete-order-desk-java.zip),
   and open it ([first launch](/swing-ui-agent/demo/tour/#download-and-run-it)).
2. **Run a recorded test:** press **Load recorded test…** in the bar at the bottom, pick `place-order`, press **▶ Run**.
   Order Desk comes with three; the app takes the order by itself and checks every total.

   <Image src={launch} alt="Order Desk right after it starts: the Orders list, and at the bottom the palette's bar with Record and Load recorded test" width={600} />
3. **Connect your agent** while the app runs:

   ```sh
   claude mcp add --transport http order-desk http://127.0.0.1:8770/mcp
   ```

   In Claude Code, also add the skills: `/plugin install swing-ui-agent --marketplace kormcrete/claude-plugins`.

4. **Ask it:** *"Create a new order for Ada Shop Ltd with 3 packs of A4 paper and 10 black gel pens, check out, and
   tell me the order number."* If it asks for a PO number, give it any.
5. **Ask again.** Now it knows the screens and sends the whole order in one `batch` call, in about half a second. Ask
   it to [save the steps as a recorded test](/swing-ui-agent/start/record-together/), and what it learned to its
   project notes.

Then [take the tour](/swing-ui-agent/demo/tour/), or open Order Desk's source in IntelliJ and record into the project:
[in IntelliJ](/swing-ui-agent/start/intellij/), [with Claude Code](/swing-ui-agent/start/claude-code/).

## Good to know

- **No changes to the app.** Add `-javaagent:`. Java 8 to 25, macOS, Linux and Windows.
  [Install](/swing-ui-agent/start/install/)
- **Your mouse and keyboard stay yours.** Input goes into the app's own event queue; other windows can be in front.
- **Waits for the app, not a timer.** Every step lets the app settle; checks retry until they hold.
  [Waiting](/swing-ui-agent/guides/waiting/)
- **Finds what a person sees.** Labels, button text, column headers and cell text, not pixel positions.
  [Targets](/swing-ui-agent/guides/targets/)
- **Exact values, your data.** A recorded test checks what is on screen, such as the cart's **Total** `€31.32`. It
  creates the data it checks or uses data you know exists.
- **Built for agents.** An element tree instead of screenshots, errors that list the near misses, and three skills
  and a driver sub-agent that teach the workflow. [Skills](/swing-ui-agent/agents/skills/)
- **Local only.** It listens on `127.0.0.1`, refuses any other address, and no tool runs commands, loads a class or
  evaluates code. [Security](/swing-ui-agent/agents/security/)
- **Your app's words (optional).** A small plugin adds reset, login and named steps such as "Add Gel pen, black to the
  cart". [Plugin vocabulary](/swing-ui-agent/plugins/vocabulary/)
- **Early.** `0.1.0-SNAPSHOT`, not on Maven Central yet; expect changes before 1.0. A recorded test file carries its
  format version, and the agent refuses one it cannot read instead of guessing.
  [Limits](/swing-ui-agent/project/limits/) · [Roadmap](/swing-ui-agent/project/roadmap/) ·
  [Recorded test format](/swing-ui-agent/reference/recorded-test-format/)
